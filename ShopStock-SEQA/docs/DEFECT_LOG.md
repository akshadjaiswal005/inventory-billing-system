# Defect Log

This is a defect-tracking template. Add an entry when a defect is reproduced. Do not label hypothetical defects as confirmed findings.

| Defect ID | Summary | Severity | Steps / evidence | Status | Fix / retest |
|---|---|---|---|---|---|
| DEF-001 | No confirmed defects recorded yet | TBD | Execute test plan and add evidence | Open for testing | Not applicable |

Suggested workflow: New → Triaged → In Progress → Fixed → Retested/Closed. Use GitHub Issues, GitLab Issues, or another issue tracker to link defects to commits and test cases.
